# Agenturzentrale (38B) — design notes

Binding art direction: dark premium command-center shell with cinematic office hero,
operational cockpit hierarchy, and clearly labelled Demo/Geplant placeholders.

## Composition (desktop)

1. Left app navigation rail (dark shell when on `/app`)
2. Upper hero: office scene + greeting + daily quote
3. “Die Lage heute” KPI strip (real counts)
4. Right command rail from `lg:`: team presence + clickable task previews + Demo/Geplant blocks
5. Operative zones: Was braucht mich jetzt? / Aufmerksamkeit / Aktive Vorgänge / Mein nächster Schritt
6. Bottom day-rhythm + quick actions

## Data rules

- Existing function → real data only
- Planned concepts → `Demo` / `Geplant` badge
- No fake XP, levels, rankings, trophies, streaks
